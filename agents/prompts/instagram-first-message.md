# Instagram First Message Template

**PLACEHOLDER** — User will provide the actual first message template.

Use this template to personalize the first DM sent to each lead.

Available variables:
- `{first_name}` — Lead's first name
- `{city}` — Lead's city
- `{brokerage}` — Lead's source brokerage
- `{state}` — Lead's state/province

Example template (replace with actual):
```
Hey {first_name}! I noticed you're doing real estate in {city}. I help agents like you book more appointments with qualified buyers and sellers. Would you be open to a quick chat about it?
```
